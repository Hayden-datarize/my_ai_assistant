## Task 6: B2 — RSS 보수적 시드 (backoff 조정 + jitter)

**Files:**
- Modify: `src/services/rss.ts` BACKOFF_MS 상수 + jitter 추가

### Step 1: 현재 backoff 확인

```typescript
const BACKOFF_MS = [200, 800];  // attempt 0 → 200ms, attempt 1 → 800ms
```

### Step 2: 새 backoff + jitter

```typescript
const BACKOFF_MS = [500, 1500];  // 보수적 (외부 API 부담 ↓)
const JITTER_RATIO = 0.2;  // ±20%

function computeDelay(attempt: number): number {
  const base = BACKOFF_MS[attempt] ?? 1500;
  const jitter = base * JITTER_RATIO * (Math.random() * 2 - 1);
  return Math.max(0, base + jitter);
}
```

### Step 3: timeout 5s 잔여 시간 spec

5s timeout 안에서 [500, 1500] 두 retry 모두 시도 가능 검증:
- attempt 0 fetch (~200ms) + delay (~500ms ±100) + attempt 1 fetch (~200ms) + delay (~1500ms ±300) + attempt 2 fetch (~200ms) ≈ 3.1s ± 0.4. **OK**.
