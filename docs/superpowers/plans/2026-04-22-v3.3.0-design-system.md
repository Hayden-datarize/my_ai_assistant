# v3.3.0 Design System Foundation — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refactor `src/styles/main.css` (1028 lines monolith) into a layered, token-driven CSS architecture with zero visual regression and zero functional change. Foundation for v3.3.1 (sidebar UX) and v3.3.2 (heatmap redesign).

**Architecture:** Split `main.css` into `tokens.css` + `base.css` + `layout.css` + `utilities.css` + `components/*.css` (6 files). Use CSS Cascade Layers (`@layer tokens, base, layout, components, utilities`) so specificity is determined by layer order, not selector weight. Add new design tokens (spacing, typography, z-index, focus-ring, motion, heatmap palette) without changing existing token names or values.

**Tech Stack:** Vite 5, TypeScript 5, Vitest 1.4, Playwright 1.42, PostCSS (via Vite). No new runtime dependencies.

**Reference spec:** [docs/superpowers/specs/2026-04-22-v3.3-uiux-design.md](../specs/2026-04-22-v3.3-uiux-design.md) §4, §5, §10.1

**Branch:** `feat/v3.3.0-design-system` (created fresh from `main` eb99e1d)

## File Structure (end state)

```
src/styles/
├── main.css              # 15~30 lines: @layer declaration + @import statements only
├── tokens.css            # ~120 lines: :root + [data-theme="dark"] + new token categories

└── components/
    ├── splash.css        # .splash-*
```

Spec §4.1 prescribed 4 component files; this plan adds `splash.css` + `onboarding.css` because those blocks are self-contained and sizeable. This is a minor clarity-driven deviation.
