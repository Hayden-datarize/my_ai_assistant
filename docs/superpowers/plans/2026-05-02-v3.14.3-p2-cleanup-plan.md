- [ ] **Step 1: Write the failing test**

> **참고 (codex P1-1)**: `JSON.stringify(NaN)` → `"null"`, `JSON.stringify(Infinity)` → `"null"`이라
> localStorage round-trip만으로는 NaN/Infinity가 `loadSeen` 필터까지 도달하지 못한다.
> Number.isFinite guard는 **방어적 invariant** — hand-edited localStorage / 미래 migration이
> JSON 우회로 raw 객체 주입할 가능성에 대비. 따라서 spec에서 `JSON.parse` 결과를
> `vi.spyOn`으로 한 번 mock해 raw NaN 주입 경로를 시뮬레이션한다.

function loadSeen(): SeenRecord[] {
  try {
    const raw = JSON.parse(localStorage.getItem(KEY) ?? '[]') as unknown;
    if (!Array.isArray(raw)) return [];
    return raw.filter(
      (r): r is SeenRecord =>
        typeof r === 'object'
        && r !== null
        && typeof (r as SeenRecord).url === 'string'
        && typeof (r as SeenRecord).firstSeenAt === 'number'
        && Number.isFinite((r as SeenRecord).firstSeenAt),  // ✅ v3.14.3 P1-1: NaN/Infinity 차단
    );
  } catch {
    return [];
  }
}
