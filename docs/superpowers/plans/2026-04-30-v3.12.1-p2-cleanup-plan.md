## Phase 1 — Data integrity guard (핵심)

### Task 1: `getCachedUser` post-migrate shape guard

**Risk model:** 외부 도구 / 다른 origin script / 사용자 직접 편집으로 localStorage `'user'` 키가 손상된 경우, `migrateUserToV2`는 spread + nullish 가드만 하므로 `xp: "abc"` 같은 비정상 값을 그대로 통과시킨다. 이후 `recordDailyAnswer`의 `u.xp += xpDelta` (`user.ts:75`)는 `NaN + 10 = NaN`으로 silent corruption — sweep도 `getCurrentTier(NaN).id`로 false fire 가능.

**Decision (이 task에서 정함):**
- Guard 정책 = **strict**. 다음 5개 필드 중 하나라도 type mismatch면 `null` 반환:
  - `name: string` (빈 문자열 OK — 온보딩 직후 가능)
  - `interests: Array<unknown>` (요소 타입은 검증 안 함 — 기존 데이터 호환)
  - `streak: number` (NaN 거부)
  - `lastActiveDate: string` (빈 문자열 OK — 처음 사용 직후)
  - `xp: number` (NaN 거부)
- `null` 반환 효과: 호출 site (`loadUserData` → 대부분 caller) 가 `if (!u) return;` 패턴 — 이미 처리됨. 손상된 데이터를 silent하게 mutate하지 않는다.
- 손상된 데이터는 **삭제하지 않음** (사용자가 복구 시도할 수 있도록 raw 보존). 신규 user 생성은 `loadUserData() === null` 후 onboarding 흐름에서 처리.
- `earnedBadges: Record<string, number>` / `gamificationMigrated: boolean` / `schemaVersion: 2` 는 `migrateUserToV2`가 nullish 가드로 채워주므로 검증 불필요.

```ts
export function getCachedUser(): User | null {
  try {
    const raw = localStorage.getItem(KEY);
    if (!raw) return null;
    const parsed = JSON.parse(raw);
    const candidate = (parsed && parsed.schemaVersion === 2)
      ? (parsed as User)
      : migrateUserToV2(parsed);
    if (!isValidUserShape(candidate)) return null;
    if (parsed?.schemaVersion !== 2) {
      // lazy migrate: 정상 v1 → v2 변환 결과만 persist (손상 데이터는 위에서 null 반환)
      localStorage.setItem(KEY, JSON.stringify(candidate));
    }
    return candidate;
  } catch {
    return null;
  }
}

/**
 * v3.12.1 (P2-NEW-2): localStorage 외부 손상으로 인한 silent NaN 차단.
 * 5개 핵심 필드 type-check만 — earnedBadges/gamificationMigrated/schemaVersion은
 * migrateUserToV2가 nullish 가드로 채워주므로 검증 불필요.
 */
function isValidUserShape(u: unknown): u is User {
  if (!u || typeof u !== 'object') return false;
  const r = u as Record<string, unknown>;
  return typeof r.name === 'string'
    && Array.isArray(r.interests)
    && typeof r.streak === 'number' && Number.isFinite(r.streak)
    && typeof r.lastActiveDate === 'string'
    && typeof r.xp === 'number' && Number.isFinite(r.xp);
}
```

export function migrateUserToV2(raw: unknown): User {

  v2.earnedBadges = v2.earnedBadges ?? {};

}
