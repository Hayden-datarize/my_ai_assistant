> **Cycle range**: parent `122dd43` (v3.35 deploy) → tip TBD.
> **Type**: 신규 user-facing 기능 (v3.21 carry 6개월 누적 C2 → v3.34 C3 청산).

## §1. Motivation

v3.21에서 Plant detail modal(Standard 6 항목 — stage/progress/unlockedAt/lastEngagedAt/wilting/counts)을 도입한 후, **read-only**로만 운영됐다. 사용자가 식물을 클릭해서 정보를 볼 수는 있어도 그 정원에 연관된 답변/스크랩/통찰로의 진입은 불가능.

v3.21 retro에 "Plant detail modal action layer (v3.22+)" 명시 후 **14 사이클(v3.22~v3.35) 연속 deferred**. 본 사이클이 청산.

### 1.1 사용자 가치

- 식물 detail 보기 → "이 식물에 쌓인 답변/스크랩을 어디 가서 볼 수 있지?" 자연스러운 질문에 즉시 응답.
- 게임화 시리즈(v3.15 Game World → v3.21 Plant modal) 완결 단계 — 정보 표시에서 탐색 진입점으로 확장.

### 1.2 본 사이클 목표 (옵션 1 — 단일 chip)

1. Plant detail modal 하단에 **navigation chip 1개** 추가 — `📚 이 분야로 archive 탐색`.
2. Click → modal close + archive tab activate + interest의 **대표 keyword** search prefill + `handleArchiveSearch()` 트리거.
3. 외부 라이브러리 0줄. Schema 변경 0. Migration 0.
4. Bundle cycle gate: index GREEN strict ≤ +300 B. archive chunk 변경 없음(plant-detail.ts는 별도 dynamic chunk).

### 1.3 옵션 비교 (brainstorming 결정)

| 옵션 | 동작 | 사이클 크기 | 정확도 | 결정 |
|---|---|---|---|---|
| **1. 단일 chip "이 분야로 archive 탐색"** | modal 하단 1 button → archive search prefill + close | XS | keyword 의존 (약함, 명시적 hint) | ✅ 채택 |
| 2. 3 chip 묶음 (답변/스크랩/통찰) | counts 라인 chip 변환 + 각 entity별 진입 | S | 동일 keyword 기반 (insight만 exact) | deferred — UX 가치 vs cluttering 검토 후 |
| 3. Answer/Scrap에 `interestId` field 도입 | schema migration + Gemini 분류 inference + archive interest UI 신규 | L | 매우 높음 | deferred — 별도 사이클 brainstorming 필요 |

**옵션 1 선택 근거**: 6개월 누적 carry 청산이 1차 목적. UX hint("탐색" 단어로 정확 filter 아님 nuance 전달)로 정확도 약점 명시. 옵션 2/3은 사용자 피드백 후 우선순위 결정.

### 2.2 bodyNode migration (v3.26 T3 graduated 패턴 활용)

**현재** (`plant-detail.ts:17-30`):

```ts
export function openPlantDetailModal(interestId: string): void {
  // ...
  const bodyHtml = renderBody(u, interestId, plant);
  openModal({
    title: `${title} 정원`,
    bodyHtml: `<div class="plant-detail-modal">${bodyHtml}</div>`,
  });
}

function renderBody(_u: User, interestId: string, plant: PlantState): string {
  // ... 6 항목 string concat
  return stageHtml + progressHtml + unlockedHtml + engagedHtml + wiltingHtml + countsHtml;
}
```

**변경 후**:

```ts
export function openPlantDetailModal(interestId: string): void {
  // ...
  const bodyNode = renderBody(u, interestId, plant);  // HTMLElement 반환
  openModal({
    title: `${title} 정원`,
    bodyNode,  // v3.26 T3 contract — listener 보존 (chip onclick)
  });
}

function renderBody(_u: User, interestId: string, plant: PlantState): HTMLElement {
  const root = document.createElement('div');
  root.className = 'plant-detail-modal';

  // 기존 6 항목 — 한 번에 innerHTML로 escape된 HTML 주입 (이미 escape 적용된 sub-string concat이므로 안전)
  // v3.26 T3 contract: bodyNode path 내에서 자체 escapeHtml 책임은 유지.
  const staticHtml = stageHtml + progressHtml + unlockedHtml + engagedHtml + wiltingHtml + countsHtml;
  // eslint-disable-next-line no-restricted-syntax -- bodyNode 내부 static HTML, 각 sub-string은 escapeHtml 적용 끝
  root.innerHTML = staticHtml;

  // v3.36 T1: action chip — DOM element + onclick listener
  const chip = makeActionChip(interestId);
  root.append(chip);

  return root;
}

function makeActionChip(interestId: string): HTMLButtonElement {
  const btn = document.createElement('button');
  btn.type = 'button';
  btn.className = 'plant-action-chip';
  btn.textContent = '📚 이 분야로 archive 탐색';
  btn.setAttribute('aria-label', '이 분야 키워드로 archive 검색');
  btn.addEventListener('click', () => navigateToInterestArchive(interestId));
  return btn;
}
```

### 2.3 navigateToInterestArchive 흐름 (Codex P1-1/P1-3/P1-4 흡수)

```ts
/**
 * v3.36 T1: Plant action chip click handler.
 * 한국어 keyword 우선 추출(P1-3) + handleArchiveSearch 동적 import(P1-1, archive handler를 stats chunk로 끌어오지 않도록).
 */
async function navigateToInterestArchive(interestId: string): Promise<void> {
  const keyword = pickSearchKeyword(interestId);
  if (!keyword) return;  // 이론상 unreachable — interestKeywords는 unknown id에도 [id.toLowerCase()] 반환

  closeModal();
  await switchTab('archive');  // lazy chunk load + tab active + #archiveSearch mount 보장

  const input = document.querySelector<HTMLInputElement>('#archiveSearch');
  if (!input) return;
  input.value = keyword;

  // dynamic import — stats chunk가 plant-detail 정적 import이라 archive handler를 끌어오지 않도록
  const { handleArchiveSearch } = await import('../handlers/archive');
  handleArchiveSearch();
}

/**
 * Codex P1-3 흡수: interestKeywords(id) 배열 = [id, ...label tokens, ...aliases].
 * [0]은 영문 id이라 한국어 archive content와 매칭 거의 안 됨. 한국어 token 우선, 없으면 fallback to id.
 */
function pickSearchKeyword(interestId: string): string | undefined {
  const tokens = interestKeywords(interestId);
  return tokens.find((t) => /[가-힯]/.test(t)) ?? tokens[0];
}

// chip click wiring (P1-4 흡수 — async rejection 처리)
btn.addEventListener('click', () => {
  void navigateToInterestArchive(interestId).catch((err) => {
    console.warn('[plant-action] navigate failed', err);
  });
});
```

**의도**:
- `closeModal()` → `await switchTab` 순서: switchTab이 archive lazy chunk load + tab active + `renderArchive()` 호출까지 끝낸 뒤 resolve (Codex P2-2 확인). 그 후 `#archiveSearch` querySelector 가능.
- dynamic import는 plant-detail이 stats chunk로 split된 현재 구조에서 archive handler 의존성 누수 차단 (Codex P1-1). bundle stats chunk + index 둘 다 archive handler 코드 안 들어감.
- async rejection은 click handler 동기 callback에서 unhandled promise 회피 (Codex P1-4) — production console.warn으로 silent fail.

### 2.4 CSS — `.plant-action-chip` (Codex P1-2 흡수 — 현행 tokens.css 매핑)

```css
.plant-action-chip {
  margin-top: var(--space-4);              /* 16px */
  padding: var(--space-2) var(--space-4);  /* 8px 16px */
  background: var(--primary-ultra-light);
  color: var(--primary);
  border: 1px solid var(--primary);
  border-radius: 999px;                    /* pill — tokens.css에 --radius-pill 없음, 직접 */
  font-size: var(--font-size-sm);
  font-weight: 600;
  cursor: pointer;
  width: 100%;
  text-align: center;
  transition: background var(--duration-fast) var(--ease-spring);
}

.plant-action-chip:hover {
  background: var(--primary);
  color: white;
}

.plant-action-chip:focus-visible {
  box-shadow: var(--focus-ring);
  outline: none;
}
```

**Token 매핑 (Codex P1-2 fix)**: `--color-primary-soft` → `--primary-ultra-light` / `--radius-pill` → 999px 직접 / `--font-sm` → `--font-size-sm` / `--easing-spring` → `--ease-spring` / `--color-on-primary` → white 직접 / `--color-focus` → `--focus-ring` (box-shadow). 신규 token 0개.

### 2.5 검색 prefill 정확도 (옵션 1의 trade-off)

`interestKeywords(id)` 첫 keyword를 search input에 prefill. 정확도는 keyword 의존 — 같은 keyword가 다른 text에 포함되면 noise.

**완화**:
- chip 라벨 `📚 이 분야로 archive 탐색` — "탐색" 단어로 정확 filter 아님 nuance 전달 (사용자 기대 조정).
- archive UI에서 사용자가 entity chip(all/answer/scrap/insight) 추가 filter 가능 (v3.27/v3.30 통합).

**향후 carry**: 옵션 3(Answer/Scrap interestId schema) 도입 시 exact filter 가능.

### 6.6 Lessons

- **L1**: **Codex 사전 review P0/P1 ROI 16사이클 연속** (v3.21~v3.36). 본 사이클 P1×4 = chunk model 검증(stats chunk static import 가정 fail) / CSS token 매핑 검증(존재 안 하는 token 사용 위험) / 매칭 정확도 검증(영문 id 한국어 archive mismatch) / async safety 검증(unhandled promise). controller가 spec 작성 시점에 잡지 못한 4건의 systemic 가정 fail-fast catch. v3.24 mandatory dispatch 정책 graduated 효과 명확.
- **L2**: **dynamic import로 chunk 경계 보존 패턴 정착** — plant-detail (stats chunk)에서 archive handler를 정적 import하면 archive handler 코드가 stats chunk로 끌려옴. 동적 `await import('../handlers/archive')` 사용 시 archive chunk 0 변동 + stats chunk만 transition cost 부담. 차후 cross-chunk navigation에서 graduated 패턴.
- **L3**: **한국어 우선 keyword fallback 패턴** — `interestKeywords(id)`는 `[영문 id, ...한국어 label tokens, ...aliases]` 순서. archive content가 한국어인 도메인에서는 `tokens.find(t => /[가-힯]/.test(t)) ?? tokens[0]` 패턴이 정확도 핵심. 영문 검색 fallback도 보존.
- **L4**: **TDD flush loop 패턴 (jsdom dynamic import)** — `await switchTab('archive')` 후 lazy chunk dynamic import + render가 multi-microtask. 단순 `await new Promise(r => setTimeout(r, 0))` 2회로 부족. 30회 5ms retry loop with early break on element mount이 정합 패턴.
- **L5**: **bundle triple record 첫 적용 (v3.35 T4 graduated + v3.36 stats 신규)** — index가 canonical gate, archive는 dynamic import 효과 입증용, stats는 chunk transition cost 가시화. 각 chunk별 의미 다름 — index strict / archive 0 expected / stats soft budget.
