```ts
// src/state/user.ts (편집)

export interface User {

}
```

## §4. E2 — Home + 인사이트 탭 상세

### 4.1 대화 정리 흐름

1. 사용자 chat ≥ 1턴 후 `📋 대화 정리하기` 클릭
2. 가드 통과 → `prompts.ts.conversationSummary` template + chat history → Gemini call (maxTokens 400)
3. Gemini 응답 → escapeHtml → chat container에 assistant bubble로 inline 표시 + "답변으로 저장 / 닫기" 2버튼
4. **저장 클릭** → `appendAnswer({ text: summary })` (기존 path 재사용 → archive + 카드뉴스 등록 + XP/streak 발동)
5. **닫기 클릭** → bubble만 남고 LS 영향 0
6. quota/network fail → 토스트 + 두 버튼 disable

### 4.2 인사이트 카드 흐름

1. 사용자 chat ≥ 1턴 후 `🎴 인사이트 카드 만들기` 클릭
2. 가드 통과 → `prompts.ts.insight` template + chat history → Gemini call (maxTokens 80)
3. Gemini 응답 → escapeHtml → 200자 trim → chat container에 미리보기 bubble + "저장 / 폐기" 2버튼
4. **저장 클릭** → `User.insights[]` push (atomic saveUser sweep) + 인사이트 탭 grid 갱신 + toast `인사이트 카드 1장 추가`
5. **폐기 클릭** → bubble만 남고 LS 영향 0
6. quota/network fail → 토스트 + 두 버튼 disable

### 4.3 인사이트 탭 grid

- container: `#insightsTab` (기존 shell, placeholder 텍스트 교체)
- layout: `display: grid; grid-template-columns: repeat(auto-fill, minmax(160px, 1fr)); gap: 12px;`

- **정렬**: 작성일 desc (신규 카드가 grid 좌상단)
- 빈 상태: 기존 placeholder 텍스트 유지
- 클릭 → detail 모달

### 4.4 인사이트 detail 모달

- 모달 패턴: `shared.openModal` (v3.3.3 graduated)
- 콘텐츠: 통찰 전문 + 작성일 + 삭제 버튼
