### 1.2 핵심 정정: C7은 단순 Lazy Import가 아님

현재 `src/main.ts`는 boot에서 `home/archive/stats/missions` handler를 모두 `Promise.all`로 import하고 `mount*Handlers()`를 호출한다. 이 구조는 cross-tab listener 누락을 막지만, archive/stats/missions handler chunk가 first-load에 같이 로드되어 v3.29 dynamic split 효과를 일부 상쇄한다.

단순히 `mount*Handlers()` 호출을 tab 진입 시점으로 미루면 `dg:archive:updated`, `dg:insights:*`, `dg:stats:*`, `dg:nav:tab-changed` 같은 listener가 등록되지 않아 cross-tab 이벤트가 유실될 수 있다. 따라서 C7의 안전한 목표는 다음이다.

- **Boot eager**: 작은 listener registrar만 import한다.
- **Home eager**: 첫 화면에 필요한 home listener/hydrate는 boot에서 등록한다.
- **Non-home lazy**: archive/stats/missions의 heavy handler 구현은 이벤트 발생 또는 해당 tab 진입 시 dynamic import한다.
- **DOM delegation lazy**: archive click delegation처럼 해당 tab DOM에만 의미 있는 listener는 첫 archive 진입 시 `mountArchiveHandlers()`에서 idempotent하게 등록한다.

## §2. Architecture

### 2.1 Listener Registrar Boundary

새로운 lightweight registrar를 추가한다.

| 파일 | 책임 |
|---|---|
| `src/ui/handlers/register.ts` | `registerCoreHandlerListeners()` 단일 entry. main.ts가 boot에서 import. |
| `src/ui/handlers/archive-listeners.ts` | archive 관련 `dg:*` listener 등록. 콜백 내부에서 `import('./archive')`. |
| `src/ui/handlers/stats-listeners.ts` | stats `dg:*` / nav listener 등록. 콜백 내부에서 `import('./stats')`. |
| `src/ui/handlers/missions-listeners.ts` | missions nav listener 등록. 콜백 내부에서 `import('./missions')`. |
| `src/ui/handlers/home.ts` | home은 first screen이므로 boot에서 직접 import해 listener 등록 유지. |

`main.ts`는 다음 형태로 바꾼다.

```ts
import { registerCoreHandlerListeners } from './ui/handlers/register';

async function bootMainApp(): Promise<void> {
  const [{ mountHomeHandlers }] = await Promise.all([
    import('./ui/handlers/home'),
  ]);
  mountHomeHandlers();
  registerCoreHandlerListeners();
  mountNav();
  mountSidebar();
  mountRewards();
  await switchTab('home');
  maybeShowWelcomeGarden();
}
```

`registerCoreHandlerListeners()`는 idempotent guard를 둔다. archive/stats/missions listener 파일은 heavy handler module을 top-level import하지 않는다.

### 2.2 C7 Event Semantics

archive registrar는 다음 이벤트를 boot에서 놓치지 않는다.

- `dg:archive:filter`
- `dg:archive:search`
- `dg:archive:period-change`
- `dg:archive:updated`
- `dg:insights:added`
- `dg:insights:removed`
- `dg:insights:updated`
- `dg:nav:tab-changed` where `tab === 'archive'`

stats registrar는 다음 이벤트를 boot에서 놓치지 않는다.

- `dg:stats:weekly-report`
- `dg:stats:growth-analysis`
- `dg:nav:tab-changed` where `tab === 'stats'`

missions registrar는 다음 이벤트를 boot에서 놓치지 않는다.

- `dg:nav:tab-changed` where `tab === 'missions'`

기존 handler module에는 event callback으로 호출할 수 있는 작은 exported functions를 추가한다. 예: `handleArchiveFilter(filter)`, `handleArchiveSearch()`, `handleArchiveUpdated()`, `handleArchiveTabChanged()`.

### 2.3 C4 Sidebar

`src/ui/sidebar.ts` drawer nav click handler는 async/await로 바꾸되, drawer close는 await 전에 유지한다.

```ts
btn.addEventListener('click', async () => {
  close();
  try {
    await switchTab(t.id);
  } catch (err) {
    console.warn('[sidebar] switchTab failed', t.id, err);
  }
});
```

이 순서가 중요한 이유: chunk load가 지연되거나 실패해도 drawer가 열린 채 stuck 되면 UX가 나빠진다.

### 2.4 C5 Mark Token

현재 토큰:

- light: `--mark-bg: #FEF3C7`, `--mark-fg: var(--text-primary)`
- dark: `--mark-bg: #78350F`, `--mark-fg: #FDE68A`

`--accent-light`는 light에서 같은 값 `#FEF3C7`지만 dark에서는 `#422006`이다. mark dark background는 `#78350F`로 더 밝고, foreground도 amber-200이다. 따라서 기본 결정은 **semantic token 유지**다. 단, lint/spec로 다음을 고정한다.

- light mark foreground/background contrast AA 이상.
- dark mark foreground/background contrast AA 이상.
- `--mark-bg` 주석에 `--accent-light`와 light 값만 같고 dark semantics가 다르다는 근거 명시.

### 2.5 Array Guard Contract

현재 `loadAnswers()`와 `loadBriefings()`는 module 진입점에서 `Array.isArray`를 확인한다.

- `src/state/persistence.ts`: `dg.answers`와 legacy `answers`가 array가 아니면 `[]`.
- `src/state/briefings.ts`: `briefings`가 array가 아니면 `[]`.

이번 사이클은 UI 3곳(archive/settings/stats)의 `.length` 직접 호출을 모두 바꾸기보다, **state module boundary contract를 회귀 spec으로 graduate**한다. corruption 시 UI caller가 TypeError 없이 동작해야 한다는 통합 spec을 추가한다.

## §5. Risk

| # | Risk | Mitigation | Priority |
|---|---|---|---|
| R1 | registrar가 heavy handler를 top-level import하면 C7 trim 효과 0 | `*-listeners.ts`는 `on`과 type-only import만 허용, handler는 callback 내부 dynamic import | P1 |
| R2 | listener idempotence 누락으로 duplicate event handling | `registerCoreHandlerListeners()` module-level boolean guard + unit spec | P1 |
| R3 | archive click delegation을 boot listener에서 dynamic import하면 모든 click마다 import check overhead | archive tab 진입 시 `mountArchiveHandlers()` 1회 idempotent 호출로 DOM delegation 등록 | P2 |
| R4 | `dg:insights:*`가 archive 첫 진입 전 발생하면 카운트/list 갱신 누락 | archive registrar가 boot에서 `dg:insights:*`를 듣고 `handleArchiveUpdated()` lazy import | P1 |
| R5 | home handler는 여전히 first-load import | home은 first screen hydrate/theme listener가 필요하므로 의도된 eager import. C7 scope는 non-home handler 제거 | P2 |
| R6 | sidebar close를 await 뒤로 옮기면 chunk load 동안 drawer stuck | spec과 test에서 close-before-await 순서 고정 | P1 |
| R7 | mark token 통합으로 dark contrast 악화 | semantic token 유지 기본안, 통합은 contrast spec이 증명될 때만 | P2 |
| R8 | Array guard를 UI별 local guard로 흩뿌리면 중복/누락 증가 | state module boundary contract 유지, corrupted storage UI no-throw spec으로 고정 | P2 |
| R9 | lessons graduate 문서가 오래된 패턴과 충돌 | `CLAUDE.md`는 cycle workflow/Codex section, `COMMON_MISTAKES.md`는 listener/test/mock path, `QUICK_START.md`는 단일 fix point만 좁게 반영 | P2 |
| R10 | 기존 archive tests가 `mountArchiveHandlers()`만 호출한 뒤 `dg:archive:*` dispatch를 기대 | event listener ownership이 registrar로 이동하므로 tests도 `registerCoreHandlerListeners()` 또는 exported handler callback 직접 호출로 같이 마이그레이션 | P1 |
