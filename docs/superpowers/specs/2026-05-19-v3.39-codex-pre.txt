## P0 (배포 전 반드시 in-cycle)
- [P0-1] v9 chain superset 범위 부족: `spec §2.2`, `src/state/user.ts:137-170`, `src/state/user.ts:203-253`, `src/state/migration.ts:413-465`. V2~V8 함수 guard 8 spot만으로 부족함. `getCachedUser`의 `<=8`, persist 조건 `!==8`, `isValidUserShape`의 `<=8`/`===8`도 v9로 확장해야 함. 특히 `migrateUserToV8`에 v9 pass-through가 없으면 v9가 v8로 downgrade될 수 있음. Fix: V2~V8 모두 v9 same-reference guard, V9 migrator 추가, user load allowlist/persist/shape guard를 v9 기준으로 변경, v9 corrupt nested reject spec 추가.
- [P0-2] archive exact filter 상태 모델 부재: `spec §3.3.2`, `src/ui/handlers/archive.ts:27-34`, `src/ui/handlers/archive.ts:276-282`, `src/ui/handlers/archive.ts:984-991`, `src/ui/modals/plant-detail.ts:103-118`. spec의 `selectedId`가 현재 archive state에 존재하지 않고, summary chip은 entity chip임. Fix: `currentInterestId` 같은 명시 state와 reset/apply 함수 정의, `navigateToInterestArchive`/insight nav chip이 이를 설정하도록 하고, answer/scrap/insight/all branch와 summary count가 동일 predicate를 쓰게 할 것.
- [P0-3] interest matching/validation silent fail: `spec §1 G2`, `spec §3.1.2`, `spec §3.2`, `src/utils/interestKeywords.ts:45-55`. spec은 `matchKeyword(text, interestId)`를 쓰지만 현재 helper는 lowercase hay + keyword token용이라 `ai_ml`, `leadership` 같은 id 직접 매칭은 대부분 false negative. 또 `user.interests[0]`, DOM dataset interestId가 `validateInterestId` 없이 저장될 수 있음. Fix: `matchesInterest(text, id)`를 만들고 `interestKeywords(id).some(...)` + lowercase + `validateInterestId`를 통과시킨 뒤 저장.
