5. **discriminated xor union 패턴 (`?never`)** — TypeScript에서 mutually exclusive option enforce. T3에서 첫 적용 + negative type test (`@ts-expect-error` both/neither)로 contract 검증. v3.27+ 신규 contract 정의 시 활용.
6. **CSS regex assertion 신뢰성** — garden-grid aria escape 회귀 spec에서 jsdom innerHTML serialization은 attribute value를 escape 안 함 발견. assertion은 DOM injection 방어 (`querySelector('img') === null`)로 검증해야 정확.
