## 1. 사이클 정의

**v3.14.4**는 v3.14.3에서 carry-forward된 backlog를 처리하면서, **lessons #1/#2/#4/#5를 영구 가드레일로 graduation**하는 cleanup 사이클이다. v3.14 시리즈를 깔끔히 닫고 v3.15 Game World로 진입하기 위한 마지막 무빚 단계.

배포 단위는 **단일 commit pack → main 직접 commit (직배포 패턴, origin remote 미등록)**. 사용자 "배포해줘" 명시 시점에만 `npm run build` → `firebase deploy --only hosting`.

### 1.1 옵션 B+를 채택한 이유 (사용자 합의)

- **옵션 A (numeric guards만)**: P3 잔품 16건이 v3.15에 또 누적됨. 사이클 entropy 차단 실패.
- **옵션 B (표준)**: 잔품 흡수 + flake timeout bump으로 균형. 단, **lessons graduation 누락**.
- **옵션 C (full)**: smoke flake centralize 정책 설계 시 scope creep 위험. 가치 대비 비용 과대.
- **옵션 B+ (채택)**: B + (가)Codex 사전·최종 review 표준화 + (나)baseline 측정 Task 0 우선화 + (다)lessons graduation. 셋 다 **future cycle 생산성 영구 향상** ROI가 높음.

### 1.2 명시 제외 항목

- **v3.15 Game World (캐릭터/정원)** — 게임화 시리즈 3/3, 별도 사이클 design 단계.
- **smoke flake centralize 정책** — 본 사이클은 simple timeout bump (5→10s)만. helper/centralize는 cold-start 2번째 등장 시점에 mechanical refactor (옵션 C 거부 사유).
