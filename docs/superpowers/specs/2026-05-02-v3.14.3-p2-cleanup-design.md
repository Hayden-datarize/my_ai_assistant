## 1. 사이클 정의

**v3.14.3**은 v3.14.2에서 누적된 backlog를 **전건 소진**(옵션 C)하는 cleanup 사이클이다:

1. 🔴 **silent corruption / known flake 3건** — 사용자 영향 가능한 항목

배포 단위는 **단일 commit pack → main 직접 commit (직배포 패턴)**. 사용자 "배포해줘" 명시 시점에만 push/배포.

### 1.1 옵션 C를 채택한 이유

- 사용자 정책 "오픈된 서비스 아니니 다 반영" — v3.13.1 / v3.14.1 / v3.14.2와 동일.
- backlog가 v3.15(Game World) 시작 전 깨끗이 정리돼야 사이클 간 entropy가 차단됨.
- per-task review 누적 polish는 **개별로는 작지만, 같은 영역**(toast/timing/spec)에 몰려 있어 한 사이클로 흡수가 효율적.

### 1.2 명시 제외 항목

- **v3.15 Game World (캐릭터/정원)** — 게임화 시리즈 3/3, 별도 사이클 design 단계.
- **새 기능 추가** — 옵션 C는 cleanup 한정. UX text rewording은 기존 메시지 교체일 뿐 새 코드 경로 없음.
- **datetime mock helper 추출** — Q1 결정 (B-prime). 현재 KST flake 1건뿐이라 helper는 over-engineering. v3.14.4+에서 2번째 KST flake 등장 시 mechanical refactor.

- **welcome-gamification mini-grid 등장 시** — `renderBadgeButton` export (현재 미등장).
