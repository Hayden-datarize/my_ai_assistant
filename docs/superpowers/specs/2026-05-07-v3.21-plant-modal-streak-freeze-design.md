### T2 — Freeze 충전 logic (regenerateFreeze)

- **경계**: `src/state/freezeEngine.ts` (신규 파일, ~40 LOC).
- **수정**:
  - `regenerateFreeze(u: User, now: Date): void` — `floor((now.getTime() - Date.parse(u.streakFreeze.lastEarnedAt)) / (7 * 86400_000))` 계산.
  - quotient > 0 && count < 2일 때 `min(quotient, 2 - count)` 만큼 +1, `lastEarnedAt += quotient * 7d`.
  - 시계 역행 (`quotient < 0`) → no-op clamp.
  - `Number.isFinite` guard.
  - KST `getDateStr` 일관 (v3.14.5 Pattern A graduated).
- **위험**: 시계 점프 (휴대폰 시간 변경 / 표준시 전환). lastEarnedAt 미래 시 quotient < 0 → clamp.
- **테스트**: 신규 vitest +6 — gap 0d/7d/14d/21d/0.5d 경계 / cap 2 clamp / 시계 역행.

### T3 — Freeze 소비 logic + `recordDailyAnswer` 주입

- **경계**: `src/state/freezeEngine.ts` (`consumeFreezeForGap` 추가) + `src/state/user.ts:155~160` (streak 분기 inject).
- **수정**:
  - `consumeFreezeForGap(u: User, gap: number): { consumed: number; preserved: boolean }`.
    - `gap = 0` → `{consumed: 0, preserved: true}` (no-op, today active).
    - `gap > 0` → `consumed = min(gap, count)`. `preserved = (consumed === gap)`. count -= consumed.
  - `recordDailyAnswer` 분기 확장:
    1. `regenerateFreeze(u, now)` 호출 (regen 먼저).
    2. `gap = today와 lastActiveDate 차이 - 1` 계산 (KST `getDateStr`).
    3. `const { preserved } = consumeFreezeForGap(u, gap)`.
    4. `u.streak = preserved ? u.streak + 1 : 1`.
  - **순서 invariant**: regen → consume → streak update → xp/missions → saveUser 1회 (atomic single-write v3.10 graduated).
- **Duolingo 정석 동작 (사용자 합의)**:
  - `gap = 0` (어제 활동) → `streak + 1`
  - `gap > 0` && `consumed === gap` (모든 결석 cover) → `streak + 1` (today 활동)
  - `gap > 0` && `consumed < gap` (freeze 부족) → `streak = 1` (reset)
- **위험**: idempotent 재제출 보호 — 기존 `if (u.lastActiveDate !== today)` 조건이 보호하므로 OK. atomic single-write 깨짐 검증 (사전 review grep).
- **테스트**: 신규 vitest +9 — gap 0/1/2/3 × freeze 0/1/2 매트릭스 의미있는 7건 + idempotent 재제출 + 순서 invariant assertion + 신규 user (lastActiveDate empty) 케이스.
