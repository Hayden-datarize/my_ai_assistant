## 1. Scope & Non-goals

### In scope

1. **Heatmap 재디자인** (parent §9 전부 + 본 spec의 보완)
   - Squircle cell: **14×14px** 데스크탑 / **20×20px** 모바일 (<768px), gap 3/4px, radius `var(--radius-xs)` / 5px
   - 좌측 weekday label 컬럼 (수직 `<ol>`) — **weekend amber tint 제거** (`.is-weekend`·`.weekend-label` 정리)
   - Inline info area + **기본 요약 1줄** (모바일 hover 없음 대비)
   - First-visit entrance animation (sessionStorage gate, reduce-motion 자동 무력화)
   - **Roving tabindex + Arrow-key 4방향 nav** (Up/Down = ±1일, Left/Right = ±7일)
   - **Enter/Space → 기존 `showDayDetail` 모달 유지** + trigger cell 저장 후 modal close 시 focus 복원 (`stats.ts` 호출자 레벨, `modals/shared.ts` 수정 없음)
   - Blank cell 요일 정렬 유지(leading/trailingBlanks 로직 그대로)
   - `.is-today` outline (신규) — 현재 미구현이라 실질 신규 기능
   - `stats.ts:hydrateHeatmap` 수정 — aria-label 부여, `title` tooltip 제거(스크린 리더 중복 방지)
   - 신규 DOM 구조 (§3.2)
   - `src/styles/components/heatmap.css` **전면 rewrite**
   - Legend 유지 + 재스타일 (labels "없음/적음/보통/많음")

2. **컴포넌트 폴리시**
   - briefing card + 공통 `.btn` base의 padding/gap/font-size/border-radius hard-coded 값을 **토큰 참조로 교체**
   - **변경 범위 제한**: variant-specific 색상(`.btn-primary`, `.btn-secondary` 등)은 건드리지 않음
   - 시각 diff 0 목표 (토큰 값 자체는 변경 없음)

3. **Test name drift rename** (v3.3.1 open item #1) — 해당 테스트 파일 편집 김에 묶어 처리

### Non-goals (명시 제외)

- **icon-system** (☰·🌱🌿🌳·🔥🎯📚 SVG화) — 별도 milestone
- **modal-system** (backdrop 토큰, `shared.ts` 모달 체계 개편) — 별도 milestone
- **focus-trap Tab modifier / FOCUSABLE selector 확장** — drawer 작업과 함께
- **archive card / settings form / badges / breakdown polish** — 이후 미니 폴리시
- **`showDayDetail` 모달 동작 변경** — 유지. 단 focus 복원 workaround는 `stats.ts` 쪽
- **새 KPI/데이터 계산 로직** — 기본 요약은 `loadAnswers` 파생값(total / streak)만
- **heatmap 임계값(`level = min(3, n)`) 변경** — 유지

## 2. Existing Landscape (실측)

### 2.1 현 마크업 ([src/ui/tabs/stats.ts:41-51](src/ui/tabs/stats.ts#L41))

```html
<div class="heatmap-wrap" style="background:var(--bg-card);...">
  <h3>📅 최근 4주 활동</h3>
  <div class="heatmap-labels" id="heatmapLabels"></div>   <!-- 상단 수평 -->
  <div class="heatmap-grid" id="heatmapGrid"></div>
  <div class="heatmap-legend">...</div>
</div>
```

- 정적 마크업은 `renderStats()`에서 `innerHTML`로 렌더
- `heatmap-wrap` 포함 여러 요소가 **인라인 style 블록** 사용 → heatmap.css로 이관 필요

### 2.2 현 heatmap.css vs 목표 — 구조 불일치

| 항목 | 현 구현 | 목표 (본 spec) |
|---|---|---|
| grid columns | `repeat(7, 1fr)` (수평 7열) | `grid-auto-columns: 14px` + `grid-auto-flow: column` (동적 4~5주) |
| label 배치 | 그리드 위쪽 수평 | 그리드 좌측 수직 |
| cell size | `aspect-ratio 1` + `min-height 28px` (≈ 50×28px) | `14×14px` 데스크탑 / `20×20px` 모바일 |
| level 색상 | `var(--primary-ultra-light)` + `opacity 0.85/0.8` | `var(--heatmap-l1/l2/l3)` + opacity 제거 |

**중요**: parent §9.1의 `grid-template-columns: repeat(4, 14px)`은 **버그**. 앱은 오늘 요일에 따라 4주 또는 5주 렌더하므로 동적 컬럼이 맞음.

### 2.3 토큰 현황 ([src/styles/tokens.css](src/styles/tokens.css))

v3.3.0 이관 완료. 본 spec에 필요한 토큰 이미 존재:

- `--space-1~12`: 4/8/12/16/20/24/32/48
- `--font-size-xs~3xl`: 12/14/16/18/20/24/32 (v3.3.1 rename 완료)
- `--radius-xs/sm/md/lg/xl`: 4/8/12/16/20
- `--duration-fast/base/slow`: 150/250/400ms
- `--ease-standard`: `cubic-bezier(0.4, 0, 0.2, 1)`
- `--shadow-sm`, `--focus-ring` = `0 0 0 2px var(--primary)`
- `--heatmap-l0~l3` (light + dark) — 이미 등록됨. parent §10.3 Task 5는 **중복 작업이므로 제외**

다크 모드 `--heatmap-l0: #1E293B`은 하드코딩되어 있어 light의 `var(--bg-input)` 참조와 정책 불일치. plan discovery 항목(§6 R6).

### 2.4 기존 테스트 ([tests/unit/heatmap.spec.ts](tests/unit/heatmap.spec.ts))

- 유지 가능: `aligns columns when today is {Mon~Sun}` (총 cell 수 7의 배수 로직)
- 삭제 대상: `marks exactly 8 weekend data cells`, `adds .weekend-label only to 토 and 일`
- Playwright에 heatmap 전용 smoke 없음 → 신규 추가 필요

### 2.5 의존성/진입점

- `loadAnswers()` → `{ date, createdAt, type, text, evaluation }[]`. heatmap에 충분
- `openModal(...)` in `src/ui/modals/shared.ts` — `showDayDetail`이 이걸 씀. API 시그니처 유지
- 이벤트 `dg:nav:tab-changed → stats` 시 `hydrateStats()` 재호출
- 이벤트 재호출과 sessionStorage 체크가 공존 → 첫 호출만 entrance animation 발동

### 2.6 제거 대상 CSS

- `.heatmap-cell.level-0.is-weekend` (amber tint)
- `.heatmap-cell.is-weekend:not(.is-blank)` (left accent line, v3.2b-polish #6)
- `.heatmap-cell.today.is-weekend` (no-box-shadow override)
- `.heatmap-labels .weekend-label`
- 기존 `.heatmap-cell { aspect-ratio ... min-height: 28px; }` 전체
- 기존 `.heatmap-cell:hover { z-index: 1; }` — 유지(덮어쓰기), but 값 정리

### 3.2 신규 DOM 구조

```html
<div class="heatmap-wrap">
  <h3>📅 최근 4주 활동</h3>
  <div class="heatmap-layout">
    <ol class="heatmap-weekday-labels" aria-hidden="true">
      <li>월</li><li>화</li><li>수</li><li>목</li><li>금</li><li>토</li><li>일</li>
    </ol>
    <div class="heatmap-grid"
         id="heatmapGrid"
         aria-label="최근 4주 활동 히트맵. 화살표 키로 탐색, Enter로 상세 보기">
      <!-- cells: <button aria-label="YYYY-MM-DD, N개 달성" tabindex="0|-1" class="heatmap-cell level-{0..3} is-today?"> -->
    </div>
  </div>
  <p class="heatmap-info" id="heatmapInfo" aria-live="polite">
    <!-- 기본값: "최근 28일 · {total}개 달성 · 최장 연속 {streak}일" 또는 empty state -->
  </p>
  <div class="heatmap-legend" aria-hidden="true">
    <span class="legend-item"><i class="legend-dot level-0"></i>없음</span>
    <span class="legend-item"><i class="legend-dot level-1"></i>적음</span>
    <span class="legend-item"><i class="legend-dot level-2"></i>보통</span>
    <span class="legend-item"><i class="legend-dot level-3"></i>많음</span>
  </div>
</div>
```

- `#heatmapLabels` id는 `<ol>`로 교체되지만 `hydrateHeatmap`은 id 대신 `.heatmap-weekday-labels`로 접근 (또는 label을 정적 마크업으로 이동하고 JS 렌더 제거)
- `role="grid"` / `role="gridcell"` 사용하지 않음 — `<button>` 기본 role 유지가 더 단순·안전
- `aria-describedby` 제거 — focus 이동 시 3중 발화 방지

### 3.3 Data flow

```
dg:nav:tab-changed { tab: 'stats' }
  → hydrateStats()
    → hydrateHeatmap():
      1. loadAnswers() → counts: Map<ISODate, count>
      2. 파생값: total (28일 합), streak (28일 내 최장 연속 활동일)
      3. 정적 label 마크업 존재 확인 (JS에서 label 렌더 안 함 — 마크업 이동)
      4. leading blanks + 28 data cells + trailing blanks 생성
         - data cell: <button class aria-label tabindex dataset.date>
         - class: heatmap-cell level-{0..3} [.is-today]
         - event listeners:
           - mouseenter/focus → updateInfo(date, count)
           - mouseleave/blur → resetInfo()
           - click + keydown(Enter/Space) → openDayDetail(cell)
           - keydown(Arrow) → moveFocus(direction)
      5. inline info 기본 요약 세팅 (total===0 empty state 분기)
      6. sessionStorage['dg-heatmap-animated'] 미존재 시:
         grid.classList.add('is-entering')
         sessionStorage.setItem('dg-heatmap-animated', '1')
         setTimeout(250) → classList.remove('is-entering')
```

### 3.4 Roving tabindex 알고리즘

- 초기: 첫 번째 **data cell**(leadingBlanks 다음 index) `tabindex=0`, 나머지 cell(blank 포함) `tabindex=-1`
- 이동: Arrow key 누를 때 현 index 저장 → 목표 index 계산:
  - Up: index − 1 (이전 날)
  - Down: index + 1 (다음 날)
  - Left: index − 7 (지난 주 같은 요일)
  - Right: index + 7 (다음 주 같은 요일)
- 경계: 목표가 blank 또는 총 cells 범위 밖이면 **이동 취소** (현 cell 유지)
- 이동 성공 시: 전 cell `tabindex=-1`, 신 cell `tabindex=0` + `focus()`

### 3.5 Inline info 포맷

- 기본 요약(포커스 없음 상태):
  - `total === 0`: `"아직 기록이 없어요. 첫 답변을 남겨보세요."`
  - 그 외: `"최근 28일 · {total}개 달성 · 최장 연속 {streak}일"`
- hover/focus 시:
  - `count > 0`: `"{M월 D일 ({요일})} · {count}개 달성"`
  - `count === 0`: `"{M월 D일 ({요일})} · 기록 없음"`
- `aria-live="polite"` — 탐색 시 스크린 리더에 전달

### 3.6 Modal focus return workaround

```ts
// stats.ts — hydrateHeatmap 내부
const openDayDetail = (cell: HTMLButtonElement, date: string): void => {
  // showDayDetail이 openModal 호출. modal 닫힘 콜백에서 focus 복원.
  showDayDetail(date, () => {
    cell.focus();  // ESC/닫기 후 원 cell로 focus 복원
  });
};
```

`showDayDetail`에 `onClose?: () => void` 선택 인자 추가. `openModal` 자체는 수정하지 않고, `showDayDetail` 내부에서 `openModal({ ..., onClose: callback })`으로 전달. `openModal` API가 `onClose`를 지원하지 않으면 plan discovery에서 `shared.ts` 확인 후 추가 필요(단, 이는 modal-system 개편이 아닌 콜백 인자 추가 수준이라 non-goal 영향 없음).

### 3.7 Reduce-motion

- `@media (prefers-reduced-motion: reduce)` 글로벌 rule이 v3.3.0 `base.css`에 있다고 가정. plan discovery에서 실측 확인.
- 존재하면 entrance animation / cell transition 자동 무력화
- 부재하면 heatmap.css에 로컬 rule 추가:
  ```css
  @media (prefers-reduced-motion: reduce) {
    .heatmap-cell, .heatmap-grid.is-entering .heatmap-cell { animation: none; transition: none; }
  }
  ```

## 4. Visual Spec

### 4.1 Cell

| 속성 | 데스크탑 | 모바일 (<768px) |
|---|---|---|
| size | 14×14px | 20×20px |
| border-radius | `var(--radius-xs)` (4px) | 5px (override) |
| gap | 3px | 4px |
| background | `var(--heatmap-l0..l3)` (opacity 없음) | 동일 |
| transition | `transform var(--duration-fast) var(--ease-standard), box-shadow …` | 동일 |
| `:hover, :focus-visible` | `transform: scale(1.25); z-index: 1;` | 동일 |
| `:focus-visible` 추가 | `outline: none; box-shadow: var(--focus-ring);` | 동일 |
| `.is-today` | `outline: 2px solid var(--primary); outline-offset: 1px;` | 동일 |
| `.is-blank` | `visibility: hidden; pointer-events: none;` | 동일 |

`.is-today` + `:focus-visible` 색 충돌(§6 R5) 해결은 plan 단계 실측 후 결정:
- (a) focus-ring 이중화(`box-shadow: var(--focus-ring), 0 0 0 4px var(--bg-card)`)
- (b) `.is-today`를 `box-shadow inset`으로
- (c) `.is-today:focus-visible` 전용 rule

### 4.7 Dark mode

- `tokens.css`의 `[data-theme="dark"]`가 `--heatmap-l0~l3` 재매핑 완료 — 추가 CSS 없음
- `--heatmap-l0` 라이트/다크 정책 일관성(토큰 참조 통일)은 §6 R6 plan discovery
- WCAG AA 대비(SC 1.4.11 non-text 3:1) 수동 점검 §5.4

### 4.8 컴포넌트 폴리시 (briefing card + `.btn` base)

- `components/cards.css` 내 briefing card 관련 selector:
  - `padding` / `gap` / `margin-bottom` hard-coded `16px`, `12px` 등 → `var(--space-*)`
  - `border-radius` hard-coded `16px` 등 → `var(--radius-*)`
- `components/buttons.css` 내 `.btn` base:
  - `padding`, `gap`, `font-size`, `border-radius` → 토큰 참조
  - `.btn-primary / .btn-secondary / .btn-ghost`의 `background / color`는 **건드리지 않음**
- 토큰 값 변경 없음 → 시각 diff 0 목표
