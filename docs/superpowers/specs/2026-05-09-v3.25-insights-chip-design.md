## §1 사이클 정체성

v3.23이 도입한 인사이트 카드(`Insight = { id, text, createdAt }`)는 grid + detail 모달까지 갖췄으나 **분야 메타가 없어 누적 시 탐색·필터가 불가능**했다. v3.23 §1.3 deferred 목록에 `인사이트 분야 chip (Gemini 분류)`로 명시되어 있고 v3.24 retro의 v3.25 후보 B로 등록되었다.

본 사이클은 **Insight에 `interestId: string` 필드를 추가**하고, 다음 세 측면으로 가치를 만든다:

1. **Write-time 자동 분류** — 기존 `PROMPTS.insight` 호출 path에 prompt 응답 형식만 확장 (`text|interestId`). **추가 Gemini 호출 0** (cap 영향 0)
2. **Insights 탭 chip 필터** — `insights.length >= 6`일 때 상단에 분야 chip toggle row, 활성 chip의 분야만 grid 표시. 카드 안에는 분야 chip 1개 시각 라벨
3. **Detail 모달 수동 분야 변경** — native `<select>` dropdown으로 사용자가 직접 정정 가능 (Gemini 분류 오류 / 마이그레이션 'unknown' 정리 path)

v3.24 T6에서 graduated된 `byInterest 'unknown' 제외` 정책과는 **다른 도메인**이다. answer.type='unknown'은 stats 분야 분포에서 제외되지만, insight.interestId='unknown'은 본 사이클에서 **'미분류' chip으로 별도 노출**한다 (사용자에게 명시적 카테고리 — 정정 가능성 보존).

### user-visible 영향

| 사용자 상태 | 기존 (v3.24) | v3.25 | 효과 |
|---|---|---|---|
| 인사이트 0~5개 | grid + detail | grid + detail + 카드 안 chip | chip 라벨만 추가 (필터 row 미노출) |
| 인사이트 ≥6개 | grid + detail | grid + 상단 chip 필터 row + 카드 chip + dropdown | 분야별 좁혀보기 가능 |
| 신규 인사이트 저장 | text만 저장 | text + interestId 자동 분류 | Gemini 분류 결과로 chip 즉시 표시 |
| 기존 v3.23 누적 인사이트 | text만 | interestId='unknown' 채움 (lazy migration) | '미분류' chip 노출 + dropdown 수동 정정 가능 |

### migrateUserToV7

```ts
import { validateInterestId } from './user';

export function migrateUserToV7(user: any): User {
  if (user.schemaVersion === 7) return user;
  const insights = (user.insights ?? [])
    .map((i: any) => ({
      id: typeof i?.id === 'string' ? i.id : '',  // 누락 → '' (filter drop)
      text: typeof i?.text === 'string' ? i.text : '',
      createdAt: typeof i?.createdAt === 'string' ? i.createdAt : new Date().toISOString(),
      interestId: typeof i?.interestId === 'string'
        ? validateInterestId(i.interestId)
        : 'unknown',
    }))
    .filter((i: any) => i.id.length > 0 && i.text.length > 0);  // 손상 entry 자동 제거
  return { ...user, insights, schemaVersion: 7 };
}
```

**id/text 누락 entry 정책**: `crypto.randomUUID()` 생성 X → 빈 string 후 filter drop으로 통일 (Codex P0-A2 fix). UUID 생성 시 본 함수가 non-idempotent + 의미 없는 entry 살림. drop이 정석.

- **id/text 누락 entry 자동 제거 정책**: v3.24 T5 `validateInsightText` graduate 이전에 저장된 손상 entry 또는 storage corruption 대비. id 누락 entry 통과 시 dedup/삭제 path 깨짐 (id 없는 카드 ✕ 클릭 불가). 마이그레이션 시점에 silent drop → corruption 폴백 안전망. 부수 효과: `crypto.randomUUID()` fallback path가 도달 불가 (filter 후 모든 entry id 보존됨)

### parseInsightResponse (utils/gemini-parse.ts)

폴백 chain (Codex P1-B1 강화 — JSON / quote / prefix / label alias 추가):

1. **JSON wrap 감지** — Gemini가 `\`\`\`json\n{"text":...}\`\`\`` 또는 raw `{...}` 반환 시 JSON 파싱 우선
2. **첫 비빈 줄 추출** — JSON 아닐 때 여러 줄 응답에서 첫 비빈 줄만
3. **markdown wrap 제거** — backtick / asterisk / dash 양끝 strip
4. **lastIndexOf('|') split** — text에 '|' 포함 가능성 차단
5. **id 후처리 (`normalizeInterestId`)** — quote wrap (`"recruiting"`) / prefix label (`interestId: ...` / `분야: ...`) strip → label alias map (한국어 `채용` / emoji `🎯 채용` → `recruiting`) → `validateInterestId` whitelist 최종 폴백

```ts
import { validateInterestId, validateInsightText } from '../state/user';
import { INTERESTS } from './categories';

// 한국어/emoji label → id alias map (Gemini가 label 직접 반환 대비)
const INTEREST_LABEL_ALIAS = new Map<string, string>(
  INTERESTS.flatMap(i => [
    [i.label, i.id] as [string, string],                                    // emoji prefix 포함 ('🎯 채용')
    [i.label.replace(/^[\p{Emoji}\s]+/u, ''), i.id] as [string, string],    // emoji prefix 제거 ('채용')
  ]),
);

function normalizeInterestId(raw: string): string {
  const stripped = raw
    .trim()
    .replace(/^["'`]|["'`]$/g, '')                  // quote wrap
    .replace(/^(interestId|분야)\s*[:：]\s*/i, '')  // prefix label
    .trim();
  if (stripped.length === 0) return 'unknown';
  const aliased = INTEREST_LABEL_ALIAS.get(stripped);
  if (aliased) return aliased;
  return validateInterestId(stripped);
}

export function parseInsightResponse(raw: string): { text: string; interestId: string } {
  // 1. JSON wrap 감지 (fenced json 또는 raw {...})
  const jsonMatch = raw.match(/\{[\s\S]*?"text"[\s\S]*?\}/);
  if (jsonMatch) {
    try {
      const obj = JSON.parse(jsonMatch[0]);
      if (typeof obj.text === 'string' && obj.text.trim().length > 0) {
        return {
          text: validateInsightText(obj.text),
          interestId: typeof obj.interestId === 'string'
            ? normalizeInterestId(obj.interestId)
            : 'unknown',
        };
      }
    } catch { /* fall through to line-based parse */ }
  }

  // 2. 첫 비빈 줄만 추출
  const firstLine = raw
    .split('\n')
    .map(l => l.trim())
    .find(l => l.length > 0) ?? '';

  // 3. markdown wrap 제거
  const stripped = firstLine
    .replace(/^[`*\-]+|[`*\-]+$/g, '')
    .trim();

  // 4. lastIndexOf('|') 기준 split
  const lastPipe = stripped.lastIndexOf('|');
  if (lastPipe === -1) {
    return {
      text: validateInsightText(stripped),
      interestId: 'unknown',
    };
  }

  const rawText = stripped.slice(0, lastPipe).trim();
  const rawId = stripped.slice(lastPipe + 1).trim();

  return {
    text: validateInsightText(rawText),
    interestId: normalizeInterestId(rawId),
  };
}
```

- **JSON wrap 폴백** — Gemini가 instruction 무시하고 JSON 반환해도 `text` field 추출 (interestId 누락 시 'unknown')
- **quote/prefix strip** — `"recruiting"` / `interestId: recruiting` / `분야: recruiting` 모두 인식
- **label alias map** — 한국어 label (`채용`) / emoji label (`🎯 채용`) 자연 매칭
- **strict whitelist 최종 폴백** — 모든 normalize 후에도 매칭 실패 시 'unknown'
- **빈 응답 / `validateInsightText` throw** → caller (`home.ts`)에서 catch → toast 'AI 분석에 실패했어요'

### Wiring (modals/insight-detail.ts)

```ts
const select = modal.querySelector<HTMLSelectElement>('.insight-interest-select')!;
select.addEventListener('change', () => {
  const newId = validateInterestId(select.value);
  const u = getCachedUser();
  const idx = u?.insights.findIndex(i => i.id === id) ?? -1;
  if (!u || idx === -1) return;
  const previous = u.insights[idx].interestId;
  u.insights[idx].interestId = newId;
  try {
    saveUser(u);
    dispatch('dg:insights:updated', { id });
    showToast('분야를 변경했어요');
  } catch (e) {
    u.insights[idx].interestId = previous;  // rollback in-memory
    select.value = previous;  // UI rollback
    showToast(getSaveErrorMessage(e));
  }
});
```
