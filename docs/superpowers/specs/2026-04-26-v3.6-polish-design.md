### T2. `isHttpsUrl` 강화

- **구현 골격** (`src/utils/url.ts`):

```ts
const HTTPS_PREFIX = /^https:\/\//i;  // case-insensitive (HTTPS:// 보존)
export function isHttpsUrl(value: unknown): value is string {
  if (typeof value !== 'string') return false;
  if (value !== value.trim()) return false;
  if (!HTTPS_PREFIX.test(value)) return false;
  try {
    const u = new URL(value);
    return u.protocol === 'https:' && u.hostname.length > 0;
  } catch {
    return false;
  }
}
```

- **JSDoc 갱신 (3가지 추가)**:
  1. host policy(IP literal/localhost reject 등)는 본 함수가 아닌 별도 `isAllowedImageHost` 류로 분기
  2. non-trimmed input → false; intentional, not error signal. Caller가 trim 책임
  3. case-insensitive prefix 보존 의도 — `HTTPS://` 입력은 통과
- **신규 reject 케이스 (vitest +6)** in `tests/unit/url.spec.ts`:
  1. `'https:foo'` → false (bare-path scheme)
  2. `'https:\\evil.com'` → false (backslash 변종)
  3. `'https:///path'` → false (empty hostname)
  4. `'https://'` → false (host 0자)
  5. `'https:./relative'` → false (bare-path 변종)
  6. `'HTTPS:foo'` → false (case-insensitive prefix 회귀 검증)
- **회귀 보존 (기존 vitest 전부 pass 필수)**: `'https://example.com'`, `'HTTPS://example.com'`, `'http://...'` reject 등
