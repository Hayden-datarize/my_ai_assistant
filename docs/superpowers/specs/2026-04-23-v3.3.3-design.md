## 4. Feature Designs

### 4.1 #1 브리핑 카드 — 풀블리드 카드뉴스

#### 4.1.1 DOM 구조
HTML5 `<a>` 내부 `<button>` 금지 규칙을 회피하기 위해 카드 본체와 액션을 분리.

```html
<article class="briefing-card" data-read="false">
  <a href="{url}" class="card-main" target="_blank" rel="noopener noreferrer"
     aria-label="{title} — {source}">
    <img class="card-thumb" src="{imageUrl}" alt="" loading="lazy" decoding="async"
         referrerpolicy="no-referrer" />
    <!-- onerror는 인라인 금지 (CSP script-src 'self'에 unsafe-inline 없음).
         JS 측에서 img.addEventListener('error', () => switchToTier2(card)) 로 바인딩 -->
    <div class="card-initial" aria-hidden="true"><!-- tier-2 fallback 시에만 렌더 --></div>
    <div class="card-overlay">
      <span class="card-source">{sourceTitle}</span>
      <div class="card-text">
        <h3 class="card-title">{title}</h3>
        <p class="card-summary">{summary}</p>
      </div>
    </div>
  </a>
  <div class="card-actions" role="group" aria-label="카드 액션">
    <button class="card-action-btn" data-action="scrap" aria-label="스크랩">♡</button>
    <button class="card-action-btn" data-action="memo" aria-label="메모">✎</button>
  </div>
</article>
```

- 원문 링크는 `.card-main`에만 있음 → 액션 버튼에서 "원문 열기" 제거 (중복)
- 액션 = 스크랩, 메모 2개

#### 4.1.2 3-Tier 이미지 fallback
`src/services/rss.ts` 확장:
- `FeedItem`에 `image?: string` 추가
- `extractImage(rawItem)` 함수:
  ```
  tier 1: rawItem.enclosure?.link (type이 'image/*'인 경우)
  tier 2: rawItem.thumbnail (rss2json이 제공)
  tier 3: rawItem.description HTML을 DOMParser로 파싱 → 첫 <img> src 추출
         (정규식 금지 — DOMParser는 브라우저 네이티브 sanitize + script 비실행 보장)
  fallback: null (tier-2-visual로 UI 처리)
  ```
- URL sanitize: `new URL(candidate)`로 파싱 + `protocol === 'https:'`만 허용, `javascript:`/`data:` 차단
- DOMParser 사용 예: `new DOMParser().parseFromString(desc, 'text/html').querySelector('img')?.getAttribute('src')`

`src/state/briefings.ts` 확장:
- `Briefing.imageUrl?: string` 추가 (optional → localStorage 마이그레이션 불필요)

**tier-2-visual (이미지 없거나 로딩 실패 시)**:
- 카드 배경 = 카테고리별 그라디언트 (소스명 해시 기반 → 5개 색상 팔레트 중 하나 결정적 할당)
- 중앙 이니셜 레터: 소스명 첫 글자, serif italic, 흰색 opacity 25%, 8rem
- 상단/하단 gradient overlay는 이미지 있을 때와 동일 유지 (일관성)

**tier 전환 플로우 (명시)**:
```
초기 렌더:
  imageUrl 존재 → data-tier="1", <img> 표시, .card-initial 숨김
  imageUrl 없음 → data-tier="2", <img> 제거, .card-initial 표시

img 로딩 실패 (addEventListener('error')):
  card.dataset.tier = '2'
  card.querySelector('.card-thumb')?.remove()
  card.querySelector('.card-initial').textContent = source[0].toUpperCase()
  // CSS가 [data-tier="2"] 에 반응하여 그라디언트 배경 + 이니셜 레터 표시
```

#### 4.1.3 CSP 확장
**변경 전**:
```
img-src 'self' data:
```
**변경 후**:
```
img-src 'self' data: https:
```
- 변경 파일: `firebase.json:11`, `index.html:7` (양쪽 동기화 — v3.2a 교훈)
- HTTP 이미지는 mixed content로 브라우저가 자동 차단 → 보안 유지
- **자가 진단 — XSS/Injection**:
  - 이미지 URL 에 `javascript:` 금지 (URL.protocol 검사)
  - `innerHTML` 미사용, `createElement` + 속성 할당만
  - `referrerpolicy="no-referrer"` 로 외부 호스트 referrer 최소 노출
  - ✅ OWASP A03(Injection), A05(Security Misconfiguration) 관점 안전

#### 4.4.4 focus-trap 통합
`src/ui/modals/shared.ts` 변경:

```typescript
import { createFocusTrap, type FocusTrap } from '../utils/focus-trap';

let activeFocusTrap: FocusTrap | null = null;
let lastFocusedBeforeOpen: HTMLElement | null = null;

export function openModal(cfg: ModalConfig): void {
  // 1. focus 저장 먼저 (closeModal이 focus 복원하기 전에 현재 상태 캡처)
  lastFocusedBeforeOpen = document.activeElement as HTMLElement | null;

  // 2. 이전 모달 정리 (focus 복원은 이미 저장 완료)
  closeModal({ skipFocusRestore: true });

  // 3. DOM 생성 (기존 로직)
  // ... wrap, innerHTML, titleEl, bodyEl ...

  // 4. aria-labelledby 연결
  const titleId = `dg-modal-title-${Date.now()}`;
  titleEl.id = titleId;
  wrap.setAttribute('aria-labelledby', titleId);

  // 5. focus trap 활성화
  activeFocusTrap = createFocusTrap(wrap);
  activeFocusTrap.activate();

  // 6. 기존 이벤트 바인딩
}

interface CloseOpts { skipFocusRestore?: boolean }
export function closeModal(opts?: CloseOpts): void {
  // ... 기존 로직 (active.remove() 등) ...
  if (activeFocusTrap) {
    activeFocusTrap.deactivate();
    activeFocusTrap = null;
  }
  // 모달 닫힘 후 이전 focus 복원 (openModal 체인 시 skip)
  if (!opts?.skipFocusRestore) {
    lastFocusedBeforeOpen?.focus();
    lastFocusedBeforeOpen = null;
  }
}
```

#### 4.5.1 `addBubble` 시그니처 확장

```typescript
interface BubbleAction {
  label: string;
  onClick: () => void;
}

function addBubble(role: 'user' | 'ai', text: string, action?: BubbleAction): void {
  const msgs = document.getElementById('chatMessages');
  if (!msgs) return;

  const b = document.createElement('div');
  b.className = `chat-bubble chat-${role}`;

  const textNode = document.createElement('span');
  textNode.textContent = text;  // XSS-safe
  b.append(textNode);

  if (action) {
    const btn = document.createElement('button');
    btn.type = 'button';
    btn.className = 'chat-bubble-action';
    btn.textContent = action.label;  // 하드코딩 문자열, XSS-safe
    btn.addEventListener('click', action.onClick);
    b.append(btn);
  }

  msgs.append(b);
  msgs.scrollTop = msgs.scrollHeight;
}
```

- `action.onClick` 콜백은 구현자 책임

import { switchTab } from '../nav';

function openSettingsWithFocus(): void {
  const isAlreadySettings = document.querySelector('.nav-item.active')?.getAttribute('data-tab-id') === 'settings';

  const scrollToField = () => {
    const field = document.getElementById('apiKeyInput');
    field?.scrollIntoView({ behavior: 'smooth', block: 'center' });

}
