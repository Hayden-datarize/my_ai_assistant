### 2.2 Data flow

```
[user 상호작용]
  ├─ 핀 토글 → handlers/archive.togglePin(entityType, id)
  │           ├─ entityType: 'answer' | 'scrap' | 'insight'
  │           ├─ user[collection].find(id).pinned = !pinned
  │           ├─ saveUser → throw 시 toast (v3.7 패턴)
  │           └─ dg:archive:updated 이벤트 → tab re-render
  │
  ├─ chip 토글 → archive-filter-chip 'click'
  │           ├─ activeChip state ('all' | 'answer' | 'scrap' | 'insight')
  │           ├─ ARIA radiogroup pattern
  │           └─ archive tab re-render (no save)
  │
  ├─ 검색 input → archive-search 'input' (debounce 200ms)
  │           ├─ compositionstart/compositionend 가드 (한국어 IME)
  │           ├─ query: trim → NFC normalize → lowercase
  │           └─ archive tab re-render (no save)
  │
  └─ XP 차트 마운트 (stats tab 진입)
              ├─ getXpHistory(30d) → daily cumulative XP
              ├─ levelUpMarkers 계산 (LEVEL_THRESHOLDS cumulative XP 기준)
              └─ SVG render (viewBox 0 0 300 80) + aria-label 텍스트 대체

[archive 렌더 합성]
  filterByChip(activeChip)
    → filterBySearch(query)
    → sortByPinFirst(items)  // pinned-first, 그 안에서 createdAt desc
    → renderCard(item)

  + (chip ≠ '전체' && pinned 항목이 다른 카테고리에 존재)
    → 카운터 표시 "다른 카테고리에 핀 N개"
```

### 2.3 검색 알고리즘
- **대상 텍스트**:
  - answer: 답변 본문 + question text
  - insight: insight text + interestId 라벨
  - scrap (seenBriefing): title + description + source
- **매칭**: `String.prototype.includes` (case-insensitive, NFC normalize)
- **비매칭**: 0건 시 `<p class="empty">검색 결과 없음</p>`
- **하이라이트**: out-of-scope (v3.28+ enhancement)
- **IME 한국어**: composition 중 input 무시, `compositionend` 후 debounce 200ms 트리거

### 2.4 핀 정렬 정책
- **pinned-first**
- 그 안에서 createdAt **desc** (최신 우선, archive 기존 정책 유지)
- chip='전체'에서도 동일 (entity 무관 통합 정렬)
- chip ≠ '전체'일 때 **다른 카테고리 핀 카운터** 노출 ("다른 카테고리에 핀 N개" — 클릭 시 chip='전체' 전환)

### 2.5 XP 차트 데이터 정책
- **데이터 소스**: `user.cumulative.daily` 우선 (v3.13 missions에서 도입). plan v1에서 schema 실존 여부 grep 검증 — 없으면 `user.xpHistory` 또는 신설 helper `getXpHistory(30d)` 정의 (T7 helper 작업)
- **30d window**: 오늘 KST 기준 -29일부터 오늘까지 최대 30 데이터 포인트
- **빈 데이터 가드**: `history.length < 2` → empty-state-svg ("아직 데이터가 없어요" 텍스트)
- **레벨업 마커**: `LEVEL_THRESHOLDS` cumulative XP 기준 — 일별 cumulative가 threshold를 cross한 날에 작은 원 마커 + `<desc>` aria 설명
- **a11y**: `<title>` + `aria-label="최근 30일 XP 추이: 시작 X, 끝 Y, 최대 Z, 레벨업 N회"`

### 2.6 insights.ts 함수 마이그레이션 정책
- T2a 진입 전 plan v1에서 grep 인벤토리 (`import.*from.*tabs/insights`)
- 흡수 vs 분리 결정 — utility 함수는 archive 또는 utils로 이전, tab UI 코드는 삭제
- T2a 후 `tsc --noEmit` 0 errors gate
