### 3.2 Glass surface 정의

**Codex 사전 review P1-1 정정**: backdrop-filter 미지원 시 translucent + 비-blur 조합이 어색해진다 → backdrop-filter `@supports` 안에 translucent도 묶고, 미지원 시 opaque로 되돌린다.

**Codex P1-2 정정**: 실제 토큰은 `--bg-card` / `--primary` (`--surface-1` / `--color-primary-vivid` 부재).

```css
:root {
  --border-glass: rgba(0, 0, 0, 0.08);
}
[data-theme='dark'] {
  --border-glass: rgba(255, 255, 255, 0.12);
}

.modal-glass {
  /* fallback: 불투명 (color-mix + backdrop-filter 한 쪽이라도 미지원 시) */
  background: var(--bg-card);
  border: 1px solid var(--border-glass);
}

/* color-mix + backdrop-filter 양쪽 모두 지원되는 환경에서만 glass 효과 활성화 */
@supports
  ((background: color-mix(in oklab, white, black))) and
  ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))) {
  .modal-glass {
    background: color-mix(in oklab, var(--bg-card) 75%, transparent);
    backdrop-filter: blur(20px) saturate(180%);
    -webkit-backdrop-filter: blur(20px) saturate(180%);
  }
}

/* 접근성 가드: 양쪽 가드 모두 다시 opaque */
@media (prefers-reduced-transparency: reduce) {
  .modal-glass {
    background: var(--bg-card);
    backdrop-filter: none;
    -webkit-backdrop-filter: none;
  }
}
```

### 3.3 Wrapper 적용 + 부모 surface override

**Codex 사전 review P2-1 정정**: wrapper 자식만 glass class 부착 시 부모 `.dg-modal-card`(`src/styles/components/shared.css:153`)의 opaque `background: var(--bg-card)`가 위에 덮여 glass 효과 거의 보이지 않음. `:has()` selector로 부모도 transparent override.

- `welcome-gamification.ts:58`: bodyHtml `<div class="welcome-game">` → `<div class="welcome-game modal-glass">`.
- `welcome-garden.ts:50`: bodyHtml `<div class="welcome-garden-modal">` → `<div class="welcome-garden-modal modal-glass">`.
- `openModal()`이 만드는 backdrop overlay + 전역 modal surface는 **TypeScript 변경 0** (전역 모달 회귀 risk 차단).
- CSS 정합 추가:

```css
/* welcome 모달이 .modal-glass child를 가질 때만 부모 .dg-modal-card를 transparent
 * 시켜 child glass가 실제 보이도록 한다. 다른 모달(.dg-modal-card 단독)은 영향 X. */
.dg-modal-card:has(.modal-glass) {
  background: transparent;
  border: none;
  box-shadow: none;
}

/* :has 미지원 fallback — Safari 15.4+/Chrome 105+/Firefox 121+ 외 환경. 미지원 시 glass
 * 효과가 약하지만 surface 자체는 유지(UX 회귀 0). */
```

> **주의**: `:has()`는 2026-05 기준 모든 evergreen 브라우저 지원. Firefox 121(2023-12) 이후 안정. 미지원 환경에서는 부모 opaque가 그대로 위에 덮여 glass가 거의 안 보이지만 모달 자체는 정상 동작.

### 3.4 a11y / 호환성

- Glass surface는 시각 효과만. focus order / aria 변경 0.
- `prefers-reduced-transparency` 가드로 접근성 회복.
- `@supports not (color-mix)` / `@supports not (backdrop-filter)` 분기 시 surface는 그대로 불투명 → UX 회귀 없음(시각 임팩트만 0).

**처리**:
```typescript
// missions-sparkle.ts
export function mountMissionsSparkleListener(): () => void {
  if (listenerWired) return () => {}; // idempotent
  listenerWired = true;
  const handler = ({ defId }: { defId: string }) => sparkleQueue.add(defId);
  on('dg:reward:mission-complete', handler);
  return () => {
    off('dg:reward:mission-complete', handler);
    listenerWired = false;
  };
}
```

```typescript
// missions-listeners.ts
export function registerMissionsListeners(): () => void {
  const cleanupTab = on('dg:nav:tab-changed', ...);
  const cleanupSparkle = mountMissionsSparkleListener();  // 신규 정합
  return () => { cleanupTab(); cleanupSparkle(); };
}
```

**Test-only hook 유지**:
- `__resetSparkleState()`는 spec에서 fresh state 확보용으로 유지. cleanup return과 분리(중복 X).

- `mountMissionsSparkleListener()` 반환 cleanup 호출 → 이후 이벤트 dispatch 시 queue 변동 0.
