## §2. Architecture

### 2.1 C2 — questionText highlight scope 확장

**현재** (`src/ui/handlers/archive.ts:570-579`):

```ts
const q = document.createElement('p');
if (a.questionText) {
  q.className = 'archive-card-question';
  q.textContent = `❓ ${a.questionText}`;  // textContent — highlight 불가
} else {
  q.className = 'archive-card-question archive-card-question--missing';
  q.textContent = '질문 정보 없음 (이전 버전 답변)';
}
card.append(q);
```

**변경 후**:

```ts
const q = document.createElement('p');
if (a.questionText) {
  q.className = 'archive-card-question';
  if (currentTokens.length > 0) {
    // eslint-disable-next-line no-restricted-syntax -- highlightHtml escapeHtml + escapeRegex 적용, <mark> only inject
    q.innerHTML = `❓ ${highlightHtml(a.questionText, currentTokens)}`;
  } else {
    q.textContent = `❓ ${a.questionText}`;
  }
} else {
  q.className = 'archive-card-question archive-card-question--missing';
  q.textContent = '질문 정보 없음 (이전 버전 답변)';
}
card.append(q);
```

**XSS 안전성**:
- `❓` 이모지는 코드 리터럴, escape 불필요.
- `highlightHtml(a.questionText, currentTokens)`는 `escapeHtml` + `escapeForRegExp` 내부 적용 후 `<mark>`만 inject — 이미 `body` highlight에서 검증된 pattern (archive.ts:587-588).
- `archive-card-question--missing` 분기는 사용자 입력 0 (코드 리터럴 only) — `textContent` 유지.

### 2.3 C5 — ranking.ts NFC normalize 1회

**현재** (`src/utils/ranking.ts:17-22`):

```ts
const normalized = fields.map((f) => ({
  weight: f.weight,
  body: f.text.normalize('NFC').toLowerCase(),
  initials: getInitialConsonants(f.text.normalize('NFC').toLowerCase()),  // 2회 호출
}));
```

**변경 후**:

```ts
const normalized = fields.map((f) => {
  const text = f.text.normalize('NFC').toLowerCase();
  return {
    weight: f.weight,
    body: text,
    initials: getInitialConsonants(text),
  };
});
```

**의미 보존**: NFC + toLowerCase는 idempotent한 string transform — `getInitialConsonants(x)` 결과 동일. 기존 9 spec 그대로 통과.

**추가** (1 case):

```ts
it('다중 field × 다중 token cross-product max', () => {
  const fields = [
    { text: 'TypeScript best practices', weight: 2 },  // field 1
    { text: 'React hooks rules', weight: 1 },           // field 2
```
